## 📖 Principais Conceitos Mapeados

- **Lógica e Algoritmos:** A base para resolver problemas passo a passo antes de escrever o código.
- **Variáveis e Tipos:** Como o Python armazena dados em memória (números, textos, valores lógicos).
- **Controle de Fluxo (`if / else`):** Estruturas que permitem ao programa tomar decisões com base em condições.
- **Laços de Repetição (`for / while`):** Formas de automatizar tarefas repetitivas e percorrer coleções de dados.
- **Funções:** Organização do código em blocos reutilizáveis para manter o projeto limpo.
